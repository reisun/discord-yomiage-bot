# スタイル説明の改善（2026-10-04）

Tev1 0.8B・systemoneのまま、「普通の事実説明や感情が不明な場合はノーマル」という指示を削除した。話者の感情・意図する読み方に近い候補を選び、短文・口語も扱う指示に置き換えた。ノーマルは事実説明・中立な文章の候補として残す。

なみだめに悲しみ・孤独・傷つき・見捨てられた気持ち・落胆、ツンツンに怒り・苛立ち・抗議、ヒソヒソに秘密の情報共有を追記した。従来generateでも共通の候補説明を使うが、今回の測定対象はsystemoneのみ。

## 比較方法

変更前後を同日の同一ローカルOllama・同一モデルで測定。各文2回、seed=20261003、文章順・候補順を前後でそろえた。通常HTTP制限2秒、warmupは時間から除外。候補説明の追記と指示変更をまとめて評価しており、個々の変更の効果は切り分けていない。稼働中botは停止していないため、完全な独占計測ではない。

短文はテストで示された短い表現と合成文章12件。ログ全体は使用しない。期待値は比較前に固定した読み方の意図であり、唯一の正解ではない。既存の合成48文も再測定した。今回の短文に合わせた改善なので、この短文の成績は未知の会話に対する精度保証ではない。

| 指標 | 変更前 | 変更後 |
|---|---:|---:|
| 短文の一致率 | 18/24 (75.0%) | 23/24 (95.8%) |
| 既存48文の一致率 | 84/96 (87.5%) | 87/96 (90.6%) |
| 既存ずんだもん候補の一致率 | 37/48 (77.1%) | 39/48 (81.3%) |
| 既存ノーマル期待文の一致数 | 14/14 | 14/14 |
| 短文の中央値 / p95 | 0.287 / 0.300秒 | 0.267 / 0.329秒 |
| 既存48文の中央値 / p95 | 0.254 / 0.297秒 | 0.276 / 0.339秒 |
| 有効応答率 | 100% | 100% |

「寂しいのだ」「僕は捨てられたのだ」は変更前にノーマルまたはささやき、変更後は両回なみだめ。「悲しいのだ」は今回は変更前から両回なみだめだった。「ここだけの話なのだ」は変更後もささやきとヒソヒソに分かれた。以前の実運用ログと再測定では候補順等が異なり、同じ文章でも判定が揺れる。

判定時間は数十ミリ秒の差で、全リクエストが2秒以内。投稿から音声再生開始までの時間ではない。既存unit test 17件、Compose設定、差分チェックも通過。

## 再実行・データ

READMEの検証環境で以下を実行する。変更前と変更後のコードで同じ引数を使い、出力先のみ変更する。

```bash
docker compose run --rm --no-deps -v "$PWD:/app" --user "$(id -u):$(id -g)" bot \
  python scripts/compare_ollama.py --target systemone=tev1:0.8b \
  --fixture tests/fixtures/short_voice_styles.json \
  --output docs/benchmarks/style-new-short.json
```

`--fixture` を省略すると既存48文を使う。原データは `docs/benchmarks/style-{before,after}-{short,full}-2026-10-04.json`。各ファイルに全判定・時間・fixture hash・モデルdigest・Ollama版を収録している。

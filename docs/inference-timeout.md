# 通常判定のタイムアウト（2026-10-04）

通常のスタイル判定は、接続・応答受信を含むHTTP全体の制限を2秒から0.75秒に短縮する。Ollamaが応答しない場合は `None` を返し、通常スタイルで読み上げを続ける。接続拒否などの失敗は制限時間を待たずに戻る場合がある。起動時ロード（120秒）とkeepalive（10秒）は別設定を維持する。

比較スクリプトは実装と同じ制限値を使い、結果JSONにも制限値を記録する。過去の比較データは当時の2秒制限の記録として変更しない。

検証: 1秒遅延するローカルHTTP応答に対し、実際の0.75秒設定でタイムアウトし `None` を返すことを確認。既存17テスト、Compose設定・差分チェックを通過した。ローカルTev1 0.8Bで既存48文を各2回測定し、96/96件で有効な応答が0.75秒以内に返った。期待スタイル一致率90.6%、p95は0.357秒。原データは `docs/benchmarks/timeout-075-2026-10-04.json`。

高負荷時やモデルがメモリから外れた直後には0.75秒を超えて通常スタイルへ戻る可能性がある。起動時warmupとkeepaliveは継続して使う。
